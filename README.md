# Monster Card Catalogue

## Features
- Main menu
- Add a monster card
- Search/Edit a monster card
- Delete the monster card
- Print full catalogue
- Exit the program

## Installation
Monster Card Catalogue requires Python and Easygui. Python 3.14.4 is recommended.
Easygui is included in the program file as easygui.py

## Information
1. ALL codes are generated by Lucas Kang for 91896, 91897 assessment.
